# Fase 4 - Práctica Simulada: Sistema Software FJ

## ¿Qué hace este proyecto?
Es una aplicación de consola desarrollada en Python, para gestionar clientes, servicios y reservas de la empresa Software FJ sin usar bases de datos. Todo se maneja en memoria mediante Programación Orientada a Objetos y los eventos o errores se guardan en el archivo registro.log.

## Archivos incluidos
* Actividad.py: Código principal con las clases (Entidad, Cliente, Servicio, Sala, Equipo, Asesoria, Reserva), las excepciones personalizadas y las 10 pruebas de simulación.
* registro.log: Historial con fecha y hora de los registros creados y los errores controlados durante la ejecución.

## ¿Cómo ejecutarlo?
1. Asegúrate de tener instalado Python 3.10 o superior.
2. Abre la terminal en la carpeta del proyecto y ejecuta el archivo py denominado:
3. Actividad.py
